# Examples

This directory is reserved for small reproducible examples and expected-output notes.

The current repository sample model is stored in `content/`.

## Commands

```bash
python noams_splitter.py content/Hinged-Locked-Chest_MultiColor.3mf --info
python noams_splitter.py content/Hinged-Locked-Chest_MultiColor.3mf --out examples/chest_output --format stl --zip --debug
```
